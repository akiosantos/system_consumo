## 📌 Sobre o Projeto

O **Sistema de Controle e Gestão de Consumo de Água e Energia** foi desenvolvido com o objetivo de automatizar processos operacionais relacionados ao tratamento de contas de consumo.

O sistema realiza o fluxo completo de processamento das informações, permitindo:

- 📥 **Baixar arquivos e faturas**
- 📄 **Extrair informações automaticamente**
- 🔍 **Filtrar dados relevantes**
- 📊 **Organizar registros de forma padronizada**
- 🔢 **Numerar informações utilizando códigos**
- 📁 **Gerar planilhas prontas para análise**

A proposta do projeto é reduzir o trabalho manual em planilhas, diminuir erros operacionais e aumentar a produtividade no controle das contas de consumo.

# 📊 Estrutura das Informações

O sistema trabalha com dados como:

| Campo | Descrição |
|---|---|
| Código | Identificação do registro |
| RGI | Registro Geral do Imóvel |
| Fornecimento | Número de fornecimento |
| Sigla | Unidade responsável |
| Local | Local de consumo |
| Endereço | Endereço do imóvel |
| Valor Bruto | Valor total da fatura |
| IR | Impostos |
| Valor Líquido | Valor final |
| Consumo Mensal | Quantidade consumida |
